# 斗兽棋规则与初始布局

本文件记录站内“其他玩法 → 斗兽棋”的联机双人规则。规则实现位于 `src/beast-chess.ts`，服务端房间位于 `server/beast-chess-service.ts`，棋盘与页面只负责交互和显示。

## 坐标与棋盘

- 棋盘为 7 列 × 9 行，列使用 `A`～`G`，行使用 `1`～`9`。
- `A1` 在左下，`G9` 在右上；代码坐标 `x=0..6, y=0..8`，显示坐标列为 `A + x`、行为 `y + 1`。
- 下方兽穴 `D1`，下方陷阱 `C1`、`E1`、`D2`。
- 上方兽穴 `D9`，上方陷阱 `C9`、`E9`、`D8`。
- 左河 `B4`、`C4`、`B5`、`C5`、`B6`、`C6`。
- 右河 `E4`、`F4`、`E5`、`F5`、`E6`、`F6`。
- 其余格为普通陆地。

## 行棋与吃子

1. 普通棋子每次向上、下、左、右走一格，不能斜走、出界或进入己方棋子所在格。
2. 不能进入己方兽穴；进入敌方兽穴立即获胜。
3. 等级从高到低为象 8、狮 7、虎 6、豹 5、狼 4、狗 3、猫 2、鼠 1。高等级可吃低等级，同级可互吃。
4. 陆地上的鼠可吃象，象不能吃普通陆地上的鼠。
5. 只有鼠能进入河流。水陆之间可以走到空格，但不能跨水陆吃子；河中鼠只能吃同在河中的敌方鼠，也只能被同在河中的敌方鼠吃。
6. 狮、虎可横跨连续两格河，或纵跨连续三格河，落在对岸紧邻的陆地格。全部经过的水格必须为空；任意一格有鼠时，不论敌我均不能跳。落点有己方棋子不能跳，有敌方棋子时按正常吃子规则判断。
7. 陷阱只削弱进入其中的敌方棋子。己方陷阱不降级；处于敌方陷阱时有效等级为 0，可以走到合法空格，但不能吃子。有效等级动态计算，离开陷阱立即恢复；被困在己方陷阱里的敌棋可以被合法到达的己方棋子吃掉。

## 胜负与和棋

- 走完一步后，进入敌方兽穴、吃光对方棋子，或轮到对方时对方没有任何合法走法，当前走子方立即获胜。
- 胜负判定优先于和棋。
- 同一完整局面第三次出现时判和。局面键包含回合方、全部在盘棋子的阵营、种类和位置；初始局面计入一次。
- 连续 100 个半回合无吃子判和。一方走一步计一个半回合，发生吃子立即清零。

## 联机棋桌

- 斗兽棋使用一张常驻双人棋桌，玩家点击下方或上方空席位，填写昵称或直接使用登录账号昵称后入座。
- 双方都点击“准备”后由服务端建立正式棋局；只有当前行棋方能够提交走棋。
- 棋桌左侧固定显示“提和、认输、退出”。提和需要对手同意；认输立即判负；进行中退出按认输结算并释放席位。
- 访客可以点击进行中或已结束的棋桌观战，观战不会占座，且不能走棋、认输、提和或重开。
- 对局结束后席位保留，双方可在同一棋桌再来一局；准备状态清空，阵营和昵称保留。
- 刷新和短暂断线会尝试恢复原席位。主动通过站内导航离开页面时会释放服务端席位。

## 本地规则测试与完整快照

- 每手走棋前保存完整局面快照。悔棋恢复棋盘、当前行棋方、被吃棋子、上一手、历史、重复局面计数、无吃子计数和终局状态。
- 重新开始恢复固定初始布局，下方先行，并清空整局历史与计数。
- 联机页面不在对局中提供悔棋或单方重开；这些操作只保留在纯规则引擎测试和后续本地回放能力中。
