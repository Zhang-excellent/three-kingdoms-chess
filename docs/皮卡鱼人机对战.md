# 中国象棋皮卡鱼人机对战

## 功能范围

- 中国象棋棋桌的一个空席位可以切换为“皮卡鱼 · 软件对手”。
- 真人执红或执黑均可使用。
- 皮卡鱼执红时，服务端在开局后自动计算第一步。
- 引擎只通过服务端 UCI 子进程运行，浏览器不会直接接触引擎二进制或权重。
- 引擎返回值先转换为站内坐标，再由 `playChineseMove` 校验和结算。
- 第一版默认单线程、64 MiB Hash、每步 800 ms 思考时间、全站同时计算一局，并允许最多两个等待任务。

## 外部引擎安装

项目不会在 Git 中保存 Pikafish 可执行文件或 NNUE 权重。请从 Pikafish 官方仓库的 Releases 页面下载与服务器 CPU 指令集匹配的 Linux 版本：

<https://github.com/official-pikafish/Pikafish/releases/latest>

推荐部署路径：

```text
/opt/pikafish/pikafish
/opt/pikafish/pikafish.nnue
```

设置权限：

```bash
sudo mkdir -p /opt/pikafish
sudo install -m 0755 pikafish /opt/pikafish/pikafish
sudo install -m 0644 pikafish.nnue /opt/pikafish/pikafish.nnue
sudo chown -R root:www-data /opt/pikafish
sudo chmod 0750 /opt/pikafish
```

可先直接检查官方 UCI 初始化和选项：

```bash
printf 'uci\nisready\nquit\n' | /opt/pikafish/pikafish
```

适配器会读取并应用实际 UCI 选项：

- `Threads`
- `Hash`
- `EvalFile`

不同官方发行版应通过上面的 `uci` 输出核对选项名称。如果引擎没有公布 `EvalFile`，但配置了 `PIKAFISH_EVAL_FILE`，自检会失败而不会忽略权重配置。

本次开发已用官方 `Pikafish-2026-09-06` 发行包实际核对，`uci` 返回的主要选项包括：

```text
Threads
Hash
Clear Hash
Ponder
MultiPV
Move Overhead
nodestime
UCI_ShowWDL
EvalFile
```

适配器只应用本功能需要的 `Threads`、`Hash` 和 `EvalFile`，其余选项保持引擎默认值。

## 服务配置

`deploy/three-chess.service` 默认使用：

```text
PIKAFISH_PATH=/opt/pikafish/pikafish
PIKAFISH_EVAL_FILE=/opt/pikafish/pikafish.nnue
PIKAFISH_THREADS=1
PIKAFISH_HASH_MB=64
PIKAFISH_MOVE_TIME_MS=800
PIKAFISH_SEARCH_TIMEOUT_MS=6000
PIKAFISH_STARTUP_TIMEOUT_MS=8000
PIKAFISH_MAX_QUEUE=2
```

参数说明：

- `PIKAFISH_THREADS`：限制为 1～4，默认 1。
- `PIKAFISH_HASH_MB`：限制为 16～1024 MiB，默认 64。
- `PIKAFISH_MOVE_TIME_MS`：每步搜索时间，默认 800 ms。
- `PIKAFISH_SEARCH_TIMEOUT_MS`：等待 `bestmove` 的硬超时，超时会终止并回收引擎进程。
- `PIKAFISH_STARTUP_TIMEOUT_MS`：UCI 握手和 `readyok` 超时。
- `PIKAFISH_MAX_QUEUE`：单进程正在计算之外允许等待的任务数，默认 2。

修改 systemd 配置后执行：

```bash
sudo systemctl daemon-reload
sudo systemctl restart three-chess
```

## 启动自检

在线上当前版本目录执行：

```bash
cd /opt/three-kingdoms-chess/current
sudo -u www-data env \
  PIKAFISH_PATH=/opt/pikafish/pikafish \
  PIKAFISH_EVAL_FILE=/opt/pikafish/pikafish.nnue \
  PIKAFISH_THREADS=1 \
  PIKAFISH_HASH_MB=64 \
  PIKAFISH_MOVE_TIME_MS=800 \
  npm run engine:check
```

正常输出包含：

- 实际引擎路径；
- NNUE 权重路径；
- `Threads`、`Hash`、`EvalFile` 等 UCI 选项；
- 初始局面的 `bestMove`。

如果路径不存在、权重缺失、UCI 握手失败、超时或未返回合法 `bestmove`，脚本会以非零状态退出。

## 浏览器验收

本地启动带有引擎配置的开发服务后，可运行：

```bash
npm run accept:pikafish
```

脚本会实际打开独立 Chrome 页面，验证真人执红与执黑、皮卡鱼自动首步、连续走子、认输、再来一局保留皮卡鱼、切回等待棋友，以及 390×844 手机视口。截图写入 `docs/验收截图/皮卡鱼-*.png`。

## 失败处理

- 引擎未配置：页面提示“皮卡鱼暂不可用”，不会占座。
- 队列已满：提示“皮卡鱼繁忙”。
- 计算超时或协议错误：保留当前棋盘与轮次，页面提供“重试皮卡鱼”。
- 旧对局迟到结果：通过对局 UUID 和当前步数校验后丢弃。
- 退出、终局、重新开局或房间清理都会使旧计算失效。
