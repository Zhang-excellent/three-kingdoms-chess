# 迷雾象棋规则与服务端视野

## 基础棋局

- 使用标准九路十线中国象棋棋盘、32 枚初始棋子和红先黑后的双人流程。
- 车、马、象、士、将、炮、兵卒的移动、阻挡、吃子、九宫和过河限制沿用中国象棋。
- 不检查将军，不强制应将，允许送将、允许走后己方将帅受攻击，也允许将帅无阻挡照面。
- 将帅同列无阻挡时，可以按现有长距离吃将走法直接吃掉对方将帅。
- 实际吃掉对方将帅立即结束；轮到一方且该方没有任何合法走法时，该方判负。
- 联机双方仍可采用现有认输、和棋、同一房间再来一局和 60 秒断线重连流程。

## 视野

对红、黑双方分别计算视野：

1. 己方全部棋子始终可见。
2. 取己方每枚棋子在当前真实盘面上的全部合法落点并集，包括可落空的格子和可吃到的敌棋所在格。
3. 只有落点可见；马腿、象眼、炮架和车炮经过的格子不会仅因参与路径判定而自动可见。
4. 视野计算不取决于当前轮到哪一方；等待对手行棋时仍保留本方视野。
5. 视野外显示深色迷雾。敌棋离开视野后立即隐藏，不记录最后已知位置。

例如己方炮隔一枚棋子可以吃到敌棋时，炮架所在格本身不一定可见；该敌棋的落点可见。

## 服务端信息隔离

- 完整棋局只保存在服务端内存。
- 每个 Socket.IO 连接只收到自身阵营的 `MistGameView`，其中包含己方全部棋子、可见敌棋、可见格点和己方合法落点。
- 进行中只向玩家返回其本方行动记录。对手从迷雾中走到迷雾中的落点时不返回起点、终点、棋子、吃子对象或轨迹。
- 己方损失通过自身棋子消失体现，不返回雾中攻击者的身份或坐标。
- 未入座页面只收到座位、准备和连接摘要，不收到棋盘或历史；第一版不开放观战。
- 终局确认后，完整棋盘、完整棋谱和结果才发送给本局红黑双方。
- 走棋错误使用通用提示，不通过错误原因泄露隐藏阻挡、炮架或攻击关系。
