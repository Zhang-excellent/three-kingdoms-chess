# 三国象棋 V0.1 · 规则与初始坐标

本文件供开发者实现与测试。作者已经确认的玩法与本轮临时约定分别记录，避免把未确定的普通象棋规则写死。

## 坐标约定

代码坐标 `x = 0..8` 从左向右，`y = 0..9` 从上向下。页面显示坐标为 `(x + 1, y + 1)`。

魏在下方，朝上前进，方向值 `-1`；蜀吴在上方，朝下前进，方向值 `+1`。河界在 `y=4` 与 `y=5` 之间。布局固定朝向，本轮没有棋盘翻转功能。

## 已确认的规则

1. 三国均存活时，曹操 → 刘备 → 曹操 → 孙权依次循环，第一手由曹操走。循环中的四个位置独立记录，魏方分别占第 1、3 位；每个位置只允许合法移动一枚本国棋子一次。
2. 蜀吴互不吃子，任何棋子都不能落在本方或盟友已有棋子的交叉点。盟友形成正常阻挡。
3. 曹操每次横、竖一格，活动范围 `x=3..5, y=7..9`。
4. 刘备、孙权每次横走一格，活动范围 `x=1..7, y=0`，即显示坐标上方底线第 2～8 路，含两端。
5. 锋向前 1 或 2 格，向后、向左、向右各 1 格；不能斜走、不能跳子。向前两格的中点必须空着。移动位置就是吃子位置。
6. 车沿横竖直线走任意格，路径为空；炮不吃子时路径为空，吃子时恰好隔一枚炮架。
7. 任意阵营、任意种类的棋子，包括主公，都可作炮架。
8. 马走日字并检查马腿；相、象斜走两格并检查象眼、不得过河；仕、士在九宫斜走一格。
9. 兵卒过河前向前一格，过河后可向前或左右一格，不能后退。魏兵位于 `y<=4`、蜀吴卒位于 `y>=5` 时视为已过河。
10. 取消对面笑限制与远距离对面笑吃主公；主公仍按自己的步长及活动范围吃子。
11. 刘备或孙权被吃，该国全部棋子立即移除，并跳过后续回合。被移除的棋子不再挡路或作炮架。
12. 轮到某国时，如果其全部棋子没有合法走法，判该国困毙；出局与清空处理同主公被吃。
13. 曹操出局，蜀吴联盟获胜；蜀吴两国均出局，曹操获胜。蜀或吴一方出局后，曹操与仍存活的联盟方严格交替；无论出局来自吃主公还是困毙，曹操都不会因此连续行动。

## 临时试玩约定

当前引擎只根据棋子移动与占位限制决定合法走法，采用吃主公判负。**不检查不得送将，不强制应将，不自动判将死。**

这一项并非作者已经确认的正式规则。后续确定应将、送将及三人判定时点后，再修改合法走法过滤与困毙/将死逻辑，并新增对应测试。

## 重复局面

已知约定是“两方重复不变作和”。具体次数、“两方”的适用范围、是否包括行棋方，以及三方重复处理未定。本轮不自动按重复判和。

## 状态更新顺序

接受走子 → 移动/吃子 → 清空被吃主公所属国家 → 检查胜负 → 根据当前循环位置与存活阵营确定下一方 → 检查该国是否困毙 → 必要时清空并按双人交替规则重新确定下一方 → 更新上一手与棋谱。

无效请求必须保持棋盘、回合位置和棋谱不变。悔棋恢复完整上一状态，包括被吃棋子、清空军队、出局标记、具体循环位置、胜负与上一手痕迹。

## 本机存档

存档同时记录规则版本与具体循环位置，棋谱中的每一手也记录其行动位置。刷新与悔棋不得仅凭当前阵营反推位置，因为魏方在四拍循环中出现两次。

旧版三拍轮次存档没有足够信息区分新规则中的两个魏方位置，不能无歧义续局。页面保留旧存档原数据、阻止直接续走，并提示用户按新规则另开一局；不得静默接成错误轮次。
