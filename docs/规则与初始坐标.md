# 三国象棋 · 三方独立试玩规则与初始坐标

本文件供开发者实现与测试。作者已经确认的玩法与本轮临时约定分别记录，避免把未确定的普通象棋规则写死。

## 坐标约定

代码坐标 `x = 0..8` 从左向右，`y = 0..9` 从上向下。页面显示坐标为 `(x + 1, y + 1)`。

魏在下方，朝上前进，方向值 `-1`；蜀吴在上方，朝下前进，方向值 `+1`。河界在 `y=4` 与 `y=5` 之间。联机玩家默认按本方视角观看：魏保持标准方向，蜀、吴显示旋转 180°；本地试玩和观战可点“翻转棋盘”。翻转仅映射画面与输入，代码坐标、初始布局、走法、棋谱和保存数据始终使用本段定义的标准坐标。

## 已确认的规则

1. 三国独立竞争。三方均存活时，曹操 → 刘备 → 孙权三拍循环，第一手由曹操走；每方每回合只允许合法移动一枚本国棋子一次。出局方跳过，剩余两方严格交替。
2. 任意两个不同阵营之间都可以按棋子走法互相吃子，包括主公；同国棋子不能互吃，也不能占据同国棋子所在位置。玩家可自行选择合作，但系统不提供固定联盟、盟友保护或共同名次。
3. 曹操每次横、竖一格，活动范围 `x=3..5, y=7..9`。
4. 刘备、孙权每次横走一格，活动范围 `x=1..7, y=0`，即显示坐标上方底线第 2～8 路，含两端。
5. 锋向前 1 或 2 格，向后、向左、向右各 1 格；不能斜走、不能跳子。向前两格的中点必须空着。移动位置就是吃子位置。
6. 车沿横竖直线走任意格，路径为空；炮不吃子时路径为空，吃子时恰好隔一枚炮架。
7. 任意阵营、任意种类的棋子，包括主公，都可作炮架。
8. 马走日字并检查马腿；相、象斜走两格并检查象眼、不得过河；仕、士在九宫斜走一格。
9. 兵卒过河前向前一格，过河后可向前或左右一格，不能后退。魏兵位于 `y<=4`、蜀吴卒位于 `y>=5` 时视为已过河。
10. 取消对面笑限制与远距离对面笑吃主公；主公仍按自己的步长及活动范围吃子。
11. 任意主公被吃，该国全部棋子立即移除，并跳过后续回合。被移除的棋子不再挡路或作炮架。
12. 轮到某国时，如果其全部棋子没有合法走法，判该国困毙；出局与清空处理同主公被吃。
13. 主公被吃、困毙或认输即判本国失败。首次出局不终局；最后存活的一方获胜，其他两方失败。曹操先出局后蜀吴继续争胜。出局顺序只作为过程记录，不评定名次。
14. 联机对弈中，只有当前轮到行棋的存活方可以发起和棋；提和方自动视为同意。所有存活阵营均同意后，本局判为和棋；任一存活阵营拒绝后继续对局。申请待决期间暂停走棋，申请方不能连续重复提和，已出局阵营不参与表决。
15. 已有一方出局时仍可提和，此时只要求剩余两方均同意；已出局阵营保持失败结果，剩余两方记为和棋。

## 临时试玩约定

当前引擎只根据棋子移动与占位限制决定合法走法，采用吃主公判出局。**不检查不得送将，不强制应将，不自动判将死。**

这一项并非作者已经确认的正式规则。后续确定应将、送将及三人判定时点后，再修改合法走法过滤与困毙/将死逻辑，并新增对应测试。

## 重复局面

已知约定是“两方重复不变作和”。具体次数、“两方”的适用范围、是否包括行棋方，以及三方重复处理未定。本轮不自动按重复判和。

## 手动和棋

手动和棋只属于联机对弈，本地同屏模式不提供。和棋申请记录提和方、全部存活阵营及各方选择；已同意人数实时同步给玩家和观战者。申请待决时，服务端拒绝继续走子；拒绝和棋、认输、主动退出或对局结束都会清除申请，下一局也会清空。

## 状态更新顺序

接受走子 → 移动/吃子 → 被吃主公所属国家失败并清空子力 → 若只剩一国则定其获胜并终局 → 从原三拍循环位置寻找下一存活方 → 检查该国是否困毙，必要时判负清空并继续寻找下一方 → 更新上一手与棋谱。首次出局后其余两方继续交替。

无效请求必须保持棋盘、回合位置、胜负和棋谱不变。悔棋恢复完整上一状态，包括被吃棋子、清空军队、出局标记、胜负、具体循环位置与上一手痕迹。

## 本机存档

存档同时记录胜负规则版本、出局顺序、各方胜负状态与具体三拍循环位置；棋谱中的每一手也记录其行动位置。刷新、悔棋与联机重连均按完整局面恢复。

旧名次、联盟或四拍规则存档与当前规则不兼容。页面保留旧存档原数据、阻止直接续走，并提示用户按新规则另开一局；不得静默按新规则载入旧局面。
