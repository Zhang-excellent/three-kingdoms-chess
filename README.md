# 三国象棋 · V0.2 三人房间联机试玩

三人同局，魏、蜀、吴独立竞争。名次只按出局先后确定。

项目同时提供本地试玩和三人房间联机。当前规则仍是试玩规则；联机服务使用 Node.js、TypeScript 与 Socket.IO，并直接复用前端使用的纯规则引擎。

## 启动试玩

环境：Node.js `^22.18.0` 或 `>=24.12.0`。

```sh
npm ci
npm run dev
```

打开终端显示的 Vite 地址。`npm run dev` 会同时启动网页和本机联机服务；网页通过 `/three-chess/socket.io` 连接服务端。

只体验不联网的本地模式，也可直接用 Chrome、Edge 等现代浏览器打开 **preview/试玩.html**。它是单文件离线产物；联机模式必须通过上述服务或已部署网站使用。

点击当前阵营的棋子，查看可走位置，再点击目标交叉点。圆点代表可走位置，红圈代表可吃子。走子后，下一位主公的头像亮起，棋盘保留上一手的起点、落点和方向。

## 已实现

- 9 路、10 横线棋盘，河界“秦岭淮河”，29 枚初始棋子。
- 魏红、蜀黑、吴绿；三方存活时按曹操 → 刘备 → 孙权三拍循环行棋，每方每回合一步。
- 全部棋种的移动、阻挡和吃子校验，含锋与主公的特殊规则。
- 任意两个不同阵营可按棋子走法互吃，同国棋子不可互吃；任意棋子可作炮架。
- 任意主公被吃或本国困毙后出局并清空子力；其余两国严格交替。第一位出局第三名，第二位出局第二名，最后存活者夺冠。
- 选中棋子反馈、合法落点与吃子提示、当前头像高亮、上一手痕迹和行棋记录。
- 悔棋、重新开局、可选音效、带规则版本、名次及轮次位置的本机自动保存，以及键盘 Enter/空格操作。旧联盟和四拍规则存档保留原数据并提示另开新局。
- 桌面与手机宽度的布局适配。
- 本地试玩与联机对弈模式切换；联机房间支持昵称、6 位房间号、邀请链接、唯一阵营与三人准备开局。
- 服务器权威保存房间、身份、阵营、棋局、精确轮次位置、出局、棋谱和结果；客户端只提交走棋意图。
- 房间内串行处理、局面版本号和请求唯一编号，拒绝越权、非法、重复和过期请求。
- 高熵重连凭证、断线保留座位、刷新完整同步，以及同一身份新连接替换旧连接。
- 等待区可随时退出；服务端立即释放席位、阵营、准备状态和凭证，空房间自动删除。等待区断线会取消准备，座位最多保留 60 秒；在线玩家可提前释放离线席位，断线者也可在期限内凭原凭证恢复。
- 断网时退出立即回到本机大厅并清理旧房间地址；服务器恢复后补发退出通知。页面区分本机已退出和服务器已确认。房间号以服务端签发的编号为准。
- 开局后可认输，按出局顺序结算名次并留在房间查看；主动退出会先认输再离开。短暂断线不判负，开局后不能移除别人的席位。
- 联机模式禁用单方悔棋与重开；多个房间完全隔离。

## 本轮范围与临时约定

联机房间首版只保存在服务器内存中。服务器进程重启后房间会丢失；本版没有账号、匹配大厅、排行榜、聊天、观战或数据库持久化。

等待区三人须全部在线、阵营不同且准备完毕才会开局。房间号显示、邀请链接、地址栏和本机重连凭证均使用服务端签发的同一编号；换房前请先退出当前房间。

**临时采用“吃主公判出局”模式。** 不强制应将，也不禁止送将；没有对面笑杀法。该模式是为了先验收棋盘与已明确的走法，不能视作作者已经确定的最终规则。

重复和棋的次数、三方重复局面的处理，以及应将、送将、将死的判定时点仍待作者确认。本轮不自动判重复和棋。详细规则与精确初始坐标见 [规则与初始坐标](docs/规则与初始坐标.md)。

## 生产运行

```sh
npm ci
npm run build
npm start
```

默认监听 `127.0.0.1:3000`，入口为 `http://127.0.0.1:3000/three-chess/`，健康检查为 `/three-chess/api/health`。systemd 与 nginx 配置见 [联机试玩与部署](docs/联机试玩与部署.md)。

验证与构建：

```sh
npm test
npm run check
npm run build
```

`npm run build` 生成 `dist/`，并更新单文件 `preview/试玩.html`。使用锁文件 `package-lock.json`，便于在不同电脑上安装相同依赖。

| 路径 | 内容 |

| `src/game.ts` | 初始布局、纯规则函数、轮次、出局、胜负、棋局校验 |

| `tests/game.test.ts` | 规则、出局、轮次与连续合法行棋测试 |

| `tests/room-service.test.ts` | 房间隔离、权限、版本、去重与重连测试 |
| `tests/socket.test.ts` | 三个独立 Socket.IO 客户端的端到端同步测试 |
| `scripts/test.mjs` | 为模拟 DOM 测试编译 Vue 组件，运行后删除临时文件 |
| `scripts/build.mjs` | 类型检查、生产构建、生成离线试玩 HTML |
| `docs/` | 精确规则、Codex 任务书与验收清单 |
